## 📱 Live Mobile Runner (Instant Browser Preview)

You can run and test the interactive mobile app right in your browser with realistic phone bezel, Dynamic Island, and role switching:

```bash
# Start the live mobile runner
npm start
```
Then open: **`http://localhost:3000`**

## 🤖 Native Android Studio Setup

1. Open Android Studio
2. Select **Open** and choose this directory: `taskflow-ai (1)`
3. The project includes generated `gradlew.bat` and `local.properties` pre-configured to your Windows Android SDK (`C:\Users\asus\AppData\Local\Android\Sdk`).
4. Click **Run (▶)** on your physical device or emulator.
